What it does

Built for a recurring job.

LiftLedger tracks every unit under your maintenance contract — building, type, install date, and test history — and works out exactly when the next Category 1 and Category 5 tests fall. The dashboard flags overdue tests, tests due in the next 30 days, and upcoming five-year cycles, so no unit slips. Built for independent elevator and escalator service companies.

  • Unit registry with type, install date, and AHJ
  • Automatic Category 1 (annual) and Category 5 (5-year) due-date engine
  • Overdue and due-in-30-days dashboard
  • Per-unit test history with printable compliance summary
  • Export and import your register as JSON
